# Snack-Shack
I have a small at cost snack shop for my employees. 
If you want to use this HTML template and prefill your @'s like venmo cashapp etc... Publish the repo and hardcode your @'s in a QR code with it
For example https://yourusername.github.io/snack-shack/?cash=YourCashtag
The link will let them fill the cart and then at purchase take them to the pay platform with the amount filled out.
